# Messina et al. (mouse Hi-M): source data and figure scripts

Scripts and source data to reproduce the figure panels of Messina et al., *Single-allele chromatin folding is organized by recurrent motifs that are reweighted across cell types and states*.

Pre-print: https://www.biorxiv.org/content/10.1101/2024.09.18.613689v3

## Repository structure

```
mouseHiM_2026/
├── Figures/          # Generated panels (Figure_1/Figure_1b/...)
├── Scripts/          # One script per figure + shared functions
├── Source_light/     # Precomputed source data used to plot the panels
├── Source_data/      # Full source data (not included in the repository)
├── PANEL_MAP.md      # Panel → script correspondence
├── requirements.txt
└── README.md
```

## Source data

The scripts read from two folders:

- `Source_light/` contains small, precomputed files (contact maps, median distance maps, decompositions, statistics). It is included in the repository and is enough to regenerate every panel.
- `Source_data/` contains the full single-allele data (distance maps, CFM decompositions, trained models). It is only needed to recompute the files of `Source_light/` and is not included in the repository because of its size.

Each panel first looks for its precomputed file in `Source_light/`. If the file is missing, it is computed from `Source_data/` and saved in `Source_light/`, so later runs only use the light files.

## Reproducing the figures

```bash
git clone https://github.com/NollmannLab-publications/Messina_etal.git
cd Messina_etal
pip install -r requirements.txt
```

All figures (removes the previous outputs, then runs every script):

```bash
cd Scripts
python run_all_figures.py
```

One figure:

```bash
cd Scripts
python Figure_1.py
python Figure_S1.py
```

Remove the generated panels:

```bash
cd Scripts
python cleanup_figures.py
```

Panels drawn by hand (schematics, microscopy images) are not generated by the scripts, see `PANEL_MAP.md`.

## Raw data and analysis code

Hi-M traces and matrices are available on OSF: https://osf.io/27dnx/?view_only=71678f1fcd924f7db81384f529c041b8

Analysis code (normalization, DAPI registration, cell-type trace selection, LDA decomposition): https://github.com/NollmannLab/Messina_etal

Hi-M data were acquired with qudi-HiM (Barho et al. 2022, https://github.com/NollmannLab/qudi-HiM) and analyzed with pyHiM release 0.7 (Devos et al. 2024, https://github.com/marcnol/pyHiM).
