# Panel map

Script that generates each panel. Output folders follow the same naming: `Figures/Figure_1/Figure_1b/`, `Figures/Figure_1_supp/Figure_S1b/`, etc.

Status: **done** (generated by the script), **to add** (section present, code not added yet), **image** (schematic or microscopy, not scripted).
